# Jikerun · 即刻开溜

一个基于 Canvas 2D、JavaScript 模块和 Web Audio 的网页小游戏。坐上转椅，在城市街景中跳过障碍、收集道具。

## 本地试玩

无需安装第三方依赖。安装 Python 3 后：

1. 下载或克隆本仓库，进入项目文件夹。
2. 运行 `python3 game/serve.py --open`。
3. 若浏览器没有自动打开，访问 <http://localhost:5173>。
4. 点击开局按钮，按空格跳跃；方向上键使用已获得的技能，P 键暂停。触屏设备可轻点空白画面跳跃。

**成功标志：**出现“一把转椅，无限可能”的首页，开始后人物坐在转椅上向前滑行。

关闭试玩：在启动服务的终端中按 Control + C。

## 手机试玩

电脑和手机连接同一 Wi-Fi，在项目文件夹运行 `python3 game/serve.py --lan`，然后在手机浏览器访问 `http://电脑的局域网IP:5173`。

**访问范围：**默认服务仅限本机；使用 `--lan` 后，同一局域网的设备可以访问游戏文件，试玩结束请关闭服务。

## 项目内容

- `game/`：可独立运行的网页代码、本地试玩服务和逻辑测试。
- `game/assets/`：网页运行时使用的图标资源。

仓库只收录网页相关文件，不包含原始视频、参考素材或效果预览。

## 运行检查

安装支持测试运行器的 Node.js 后，在项目文件夹运行：

```bash
cd game
npm test
```

**成功标志：**测试结果中失败数为 0。

最高分、声音设置和城市轮换位置保存在当前浏览器。本项目没有账号系统、联网排名或付费功能。

即币是可累加的本局道具，拾取后右上角显示持有数量。持有即币摔倒后，可点击“原地复活”消耗一枚，保留得分并从当前位置继续，附带 1 秒保护；即币用尽后显示“再试一把”。重新开局会清空本局即币。

小宇宙会像星星一样从空中飞过，跳起即可拾取。人物双手抓住星环两端，每次轻点屏幕或按空格向上抬升，不操作则自然下降，抬升力度与普通起飞一致。左下角显示原版图标和“小宇宙带你飞”。效果持续 10 秒；结束时星球飞走，人物受保护地缓慢落地。它与高跳、二段跳、起飞共用移动道具栏，重复拾取刷新时间，换成其他移动道具时星球也会飞走。

生辰是落在地上的白色时钟，直接滑过即可拾取。左下角显示生辰 App 图标、“生辰为你续一秒”和剩余次数。每次拾取补满 3 次机会，没有持续时间限制；贴近障碍物仍未起跳时自动扣 1 次并进入慢放，从触发到碰撞约有 3 秒，障碍物会持续靠近，不会停住。及时轻点屏幕或按空格后，以慢动作跳过障碍，再恢复原速度；继续不跳或起跳太晚仍会正常碰撞摔倒。无敌、保护和飞行期间不消耗机会；它可与其他技能同时持有，重新开局会清空。
